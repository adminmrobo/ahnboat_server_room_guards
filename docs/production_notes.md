# 서버실 지킴이 — 조수(하루)·시아·모아 루프 영상 세트

ahnboat.xyz 서버실(Reon Ahn's Lab Server) 입구와 안쪽에 붙이는 세로 루프 영상.
콘셉트: **서버실을 지키는 조수와 인턴들**. 하루의 기존 영상 두 편을 템플릿으로 삼아
시아·모아도 같은 방·같은 화풍·같은 길이로 만들었습니다.

### HTML 최소 예시

```html
<video autoplay loop muted playsinline
       poster="loops/SR_sia_poster.png"
       style="aspect-ratio:9/16;object-fit:cover">

  <source src="loops/SR_sia_loop.mp4"  type="video/mp4">

```

`muted` 와 `playsinline` 은 필수입니다 (모바일 자동재생 정책).

## 편성 (5박자)

| 박자 | 역할 | 초 |
|---|---|---|
| ② | 주 자세 · 올려다보며 눈 맞춤 | 3.0 |
| ① | 일하는 중 | 2.5 |
| ③ | 성격 한 방 | 2.5 |
| ④ | 눈 클로즈업 (시그니처) | 1.5 |
| ⑤ | 인사 → ② 자세로 복귀 | 2.5 |

**②를 맨 앞에 둔 이유**: 페이지에 붙는 순간 첫 프레임이 노출되는데 ①(타이핑)은
옆모습이라 눈이 마주치지 않습니다. ②로 시작해 ⑤가 그 자세로 돌아오면 훅과 이음매를
동시에 잡습니다. 지침서 원안(① 시작)보다 이쪽이 유리합니다.

**모아만 13.38초인 이유**: ⑤에 "찻잔을 집어 올려다보기" 동작이 한 박자 더 들어갑니다.
마지막 프레임이 ②(찻잔 든 자세)와 일치해야 루프가 맞으므로 줄이지 않았습니다.

## 제작 메모 — 다시 만들 때 반드시 알아야 할 것

### 1. 템플릿의 방은 연구실이다
T1~T5 프레임의 배경은 알케미 연구실(플라스크·나무 선반)입니다. 그대로 참조하면
인물만 서버실로 옮겨도 배경이 오염됩니다. **인물 없는 서버실 플레이트
(`stills/SR_plate_server_room.jpg`)를 캐논으로 먼저 세우고, "방은 플레이트,
구도는 템플릿"으로 역할을 갈라 지시**해야 합니다. 이게 세 캐릭터의 방을 하나로
묶는 유일한 방법이었습니다.

### 2. 프레임 잠금 문구만으로는 부족하다
"static camera" 로도 영상 모델은 좌우 드리프트·줌아웃을 냅니다. 효과 있었던 지시:
- 대상·스툴·램프의 **화면상 위치**를 못박기
- "첫 프레임과 마지막 프레임에서 같은 크기"
- "카메라는 삼각대에 고정, 이동 없음"을 별도 문단으로

### 3. 동작이 여러 단계면 마지막 자세까지 문장으로 못박기
"찻잔을 다시 집어 시작 자세로" 만으로는 찻잔을 안 집었습니다.
`clip ENDS with…` + `final frame must show: …` 처럼 **끝 상태를 명시**해야 들어옵니다.

### 4. 동작이 긴 컷은 클립 길이를 동작 완료 지점까지 확보
모아 ⑤를 2.5초로 자르니 숙여 집는 도중이 잘려 이음매가 깨졌습니다(오차 15.39).
컷 구간을 1.3초부터로 다시 잡아 해결. 동작 단계가 많은 컷은 트림 지점을
동작 완료 이후로 잡으세요.

### 5. 루프 이음매는 프레임 유사도로 측정
⑤ 마지막 프레임 vs ② 첫 프레임을 그레이스케일 96×168로 리사이즈 후 평균 절대차.
- 3 이하 = 양호 (시아 3.30 · 하루 4.49)
- 7 이상 = 실물 결함, 재렌더 또는 컷 구간 재조정
밝기 차이는 지표로 쓰지 마세요 (전 편 ±3.7 이내로 무해했습니다).

### 6. 영상 모델은 오디오를 항상 붙여서 반환
`audio_enable:false` 를 줘도 오디오 스트림이 딸려 옵니다. 조립 시 `-an` 필수.

## 조립 명령 (ffmpeg)

```bash
# 컷 자르기 + 규격 통일
ffmpeg -ss 0 -t 3.0 -i S2.mp4 -an \
  -vf "scale=720:1280:flags=neighbor,fps=24,setsar=1" \
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -movflags +faststart out.mp4

# 이어붙이기
printf "file 'c1.mp4'\nfile 'c2.mp4'\n" > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy loop.mp4

# 웹용 webm
ffmpeg -i loop.mp4 -c:v libvpx-vp9 -b:v 0 -crf 44 -row-mt 1 -an \
  -pix_fmt yuv420p -deadline good -cpu-used 2 loop.webm
```

`scale=...:flags=neighbor` 는 픽셀 계단을 보존합니다. 기본 bicubic을 쓰면
픽셀아트가 뭉개집니다.

## 사용한 모델

| 단계 | 모델 | 비고 |
|---|---|---|
| 정지 그림 17장 | GPT Image 2 | 이미지당 ~3크레딧 |
| 영상 15편 | MiniMax H3 Lite | 편당 ~60크레딧 · 768p · 5초 생성 후 트림 |

Seedance 2.5(편당 ~580)가 픽셀 유지에 가장 안정적이지만, 이 작업은 카메라 무빙이
없는 고정 구도라 저가 모델로 충분했습니다.

## 미완성 / 선택 사항

- **단체 컷 영상화** — `stills/SR_group_guards.jpg` 정지 이미지만 있습니다.
  세 명이 호흡하고 모아가 손 흔드는 5초짜리로 만들 수 있습니다.
- **모아 12초 맞추기** — 13.38초라 옆에 나란히 붙이면 주기가 어긋납니다.
  ⑤를 줄이거나 찻잔 집기 동작을 빼는 방식.
- **원본 컷 SR-S6 / SR-M6** — 지침서의 대체 컷(엎드려 졸기 · 빼꼼)은 만들지 않았습니다.
